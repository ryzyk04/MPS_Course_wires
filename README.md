# Головоломка «Провода»

Головоломка сделана на основе Arduino Uno. Игрок разрывает нужные провода по правилам задания. Лента показывает цвет каждого из пяти проводов, отдельный светодиод показывает состояние игры.

## Подключение

| Элемент | Пины Arduino Uno | Подключение |
|---|---|---|
| Провода 1–5 | D3–D7 | Каждый провод замыкает свой вход на GND. Внутренние подтяжки дают LOW при замкнутом проводе и HIGH при разрыве. |
| Лента из пяти WS2812B | D8 | DIN через резистор 330 Ом. По одному пикселю на провод. |
| Индикатор состояния WS2812B | D9 | DIN через отдельный резистор 330 Ом. |
| I²C | A4 (SDA), A5 (SCL) | Линии общей шины. |
| Питание | 5V, GND | Лента и индикатор питаются от 5 В. Земля общая для всех модулей. |

## Текущая прошивка

Код пока рассчитан на стенд: D8 управляет лентой из восьми пикселей, D9 читает кнопку, D10/D11 связывают Uno с ESP32 по UART. Uno опрашивает Simon и «Лабиринт» по I²C. Подключение из таблицы будет использоваться после переноса прошивки.

Параметры игры и обмена находятся в [include/Config.h](include/Config.h). Подключение стенда и протокол описаны в [docs/bus.md](docs/bus.md).

## Сборка и тесты

Из каталога проекта:

```powershell
pio run
python test/run_tests.py
```

Для сборки нужен PlatformIO и соседний каталог `puzzle_bus`. Для тестов нужны Python и `g++`.
